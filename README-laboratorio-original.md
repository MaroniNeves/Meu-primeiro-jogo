# Ateliê Arcano 120 magias

Aba V8: 100 habilidades 3D originais. Aba Rollshade: 20 efeitos animados.

Ao alternar de aba, uma navegação completa descarrega o contexto gráfico anterior; dois renderizadores não são executados simultaneamente.

Originais preservados em atelie-arcano-anime-v8/ e atelie-arcano-rollshade-piloto/preview/.
