# Meu Primeiro Jogo — Ateliê Arcano

Projeto independente com floresta 3D, grama Quaternius, personagem animado,
clima, solo, água e simulação ecológica.

**[Abrir jogo](./index.html)** · [Versão laboratório](./agua.html)

Para executar localmente, utilize um servidor HTTP simples na raiz do repositório
(por exemplo `python3 -m http.server 8000`) e abra `index.html`.

## Origem da migração
Os arquivos foram importados da pasta `atelie-arcano-laboratorio/` do projeto
anterior. O novo repositório possui arquivos e histórico próprios; o jogo não
depende de importar scripts, modelos ou texturas da pasta antiga.

As bibliotecas, o personagem Xbot e alguns recursos opcionais podem ser
carregados de URLs públicas de terceiros, como já acontecia na origem.
